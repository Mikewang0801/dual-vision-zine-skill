# Dual Vision Zine · 双生画面

> 同一张照片，两种视觉结局。

`scene-distillation-zine-v1-3` 是一个面向 Codex 等 AI 代理的双方案视觉创作 skill。它会先理解照片的主体、空间关系、情绪残留与视觉节奏，再根据用户意图生成一种或两种结果：

- **方案 A · 原图高级感**：保留真实照片，以克制的版式、文案、图形、色彩与留白完成编辑海报化。
- **方案 B · 意境化重构**：不保留照片像素，把人物、场景与关系提炼为原创纸刊插画。

未指定模式时，默认同时生成 A、B 两张互为呼应但构图不同的作品。

## 个性化设计重点

- 双方案默认输出，而不是在“保留照片”和“完全重绘”之间二选一；
- 支持单图、多格拼图、平行场景与前后对比的来源结构识别；
- 将人物识别线索分为匿名轮廓、语义相似和可辨认形象三个等级；
- 不替用户虚构人物关系、时间顺序或个人经历；
- 将“高级感”定义为层级、留白、字体、裁切与来源驱动图形，而非黑金、英文或模板化奢华；
- 采用一次有限质量检查，仅在客观失败时进行一次定向修正；
- 保留 `单色块模式`，用于一个连续高饱和色块的意境化结果。

## 模式

| 模式词 | 输出 |
|---|---|
| 未指定 / `双方案模式` | 原图高级感 + 意境化重构 |
| `原图高级感模式` | 仅方案 A |
| `意境化模式` | 仅方案 B |
| `单色块模式` | 仅方案 B，且只允许一个连续彩色区域 |
| `双方案模式 + 单色块模式` | 标准方案 A + 单色块方案 B |

## 示例

```text
用 $scene-distillation-zine-v1-3 处理这张照片
```

```text
原图高级感模式。保留人物和场景，文案只用“树影之间”。
```

```text
意境化模式。不要保留任何照片像素，但要留下人物的眼镜、衣服轮廓和道路方向。
```

```text
双方案模式 + 单色块模式。意境化方案使用一个连续的钴蓝色块。
```

## 安装

把本目录复制到个人 Codex skills 目录，或使用 Codex 的 skill 安装工具从 GitHub 仓库安装。

安装后可通过 `$scene-distillation-zine-v1-3` 显式调用。
